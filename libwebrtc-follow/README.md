# libwebrtc-follow

libwebrtc の追従記録。libwebrtc のバージョン更新時に、パッチ適用やビルドの確認結果を
時系列で記録していくナレッジベース。

## 記録形式

月ごとのファイル (`<YYYY-MM>.md`) に、バージョン (milestone.branch + commit hash) 単位で追記する。

```markdown
# 2026-08

## 2026-08-03 152.7922 f20ebb8a

- パッチ適用: 成功 / 失敗
- 失敗パッチ: <パッチ名>
- 修正方針: <どう修正すればいいか>
- 理由: <なぜその修正が必要か>
- fuzz 警告: あり (<パッチ名>) / なし
- ビルド: 成功 / 失敗 / 未実施
- 残課題: <次の作業への引き継ぎ事項>
```

同じブランチのコミットポジション更新 (position +1) は、同じファイルに新しい日付のセクションとして追記する。

## 記録者

- 通常は `agents/libwebrtc-update-check` が自動で追記する
- 手動で追記してもよい。形式は上記に従うこと
